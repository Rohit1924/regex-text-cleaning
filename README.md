# Regex Text Cleaning

A beginner-friendly Python project that uses **Regular Expressions (Regex)** to clean and process text data.

## 📌 About

This project demonstrates how Python Regex can be used to remove unwanted patterns from text, such as subtitle timestamps and unnecessary characters.

## 🛠️ Technologies Used

- Python
- Regular Expressions (`re`)
- Google Colab

## 🔍 What This Project Does

- Uploads a text file in Google Colab
- Reads the uploaded file
- Detects subtitle timestamp patterns using Regex
- Removes timestamps from the text
- Removes unwanted single quotes
- Cleans unnecessary characters from the text
- Produces cleaned text

## 📚 Regex Concepts Used

- `re.compile()`
- `re.findall()`
- `re.sub()`
- `\d` — matches digits
- `\w` — matches word characters
- Regex patterns

## 🚀 How to Run

1. Open the notebook in **Google Colab**.
2. Upload your text file.
3. Run the cells step by step.
4. The Regex patterns will clean the text.
5. View the final cleaned text.

## 📂 Project File

```text
Regex_Text_Cleaning.ipynb
```

## 🎯 Learning Goal

The main goal of this project is to understand the basics of **Regular Expressions in Python** and apply them to a real text-cleaning task.
